# LPC1114 温度记录仪

基于 LPC1114、DS18B20 和 DS1307 的温度记录项目。设备按秒采集温度，将温度和时间写入 SPI Flash，并通过 USB 转串口查询、设置时间和导出历史记录。

项目资料：[开发板原理图 PDF](docs/hardware/LPC1114-DevKit_V5.6.pdf) · [系统连接和软件流程](docs/design.md) · [测试截图与说明](docs/testing.md)

## 功能

- DS18B20 12 位温度转换，读取时检查 CRC。
- DS1307 实时时钟；串口设置和读取时间。
- SPI Flash 按时间保存记录，断电后恢复记录数量。
- 串口导出 CSV、查询记录、暂停和恢复记录。
- 运行状态灯和功能按键。

## 硬件连接

| 功能 | 引脚或器件 |
| --- | --- |
| 温度传感器 | DS18B20 DQ → PIO0_6；4.7 kΩ 上拉至 3.3 V，VDD 接 3.3 V，GND 共地 |
| RTC | DS1307 I²C：PIO0_4 / PIO0_5；断电计时需要 RTC 后备电池 |
| 存储 | SSP1 SPI Flash；软件检查 JEDEC ID `0B 40 13` |
| 串口 | PIO1_6 / PIO1_7，通过 CH340 连接电脑 |
| 指示灯 | PIO1_9，低电平点亮 |
| 功能按键 | PIO3_5，低电平按下；切换记录与暂停 |

USB／电池供电和电源切换由开发板硬件实现，请根据实际原理图确认。PIO0_6 为当前固件的传感器引脚。

## 编译与下载

1. 使用 Keil µVision 打开 `Blinky.uvproj`，选择 **LPC1114 Flash** 目标。
2. 安装适用于 LPC1114/302 的设备支持和工程所需的 ARM 编译器；工程源文件引用的 `LPC11xx.h` 由设备支持包提供。
3. 执行 Rebuild，配置与你的 SWD 下载器匹配的调试驱动，选择 SW 接口并下载。
4. 使用串口工具连接设备；串口与 SWD 下载接口承担不同功能。

工程来源环境为 Keil MDK 4.74；其他版本需要自行确认编译器与设备支持包兼容性。

## 串口使用

参数：**115200 波特，8 位数据，奇校验，1 位停止位，无流控**。单字符命令立即执行。

| 命令 | 功能 |
| --- | --- |
| `TYYMMDDHHMMSS` | 设置 RTC，例如 `T261102143000` |
| `Q` | 读取当前时间 |
| `D` | 导出开始执行时已有的全部记录，以 `END` 结束 |
| `R` / `H` | 查看最后 1 条 / 10 条记录 |
| `C` | 查看记录数 |
| `S` / `P` | 开始 / 暂停记录 |
| `ERASE` | 擦除全部温度日志扇区 |
| `?` | 显示帮助 |

导出格式为 `index,time,temp_c`。串口工具若给每个接收片段添加时间戳，保存的文本可能不再是标准 CSV；建议保存原始接收数据。

**`ERASE` 会删除所有温度日志。** 先用 `D` 导出并保存，确认收到 `END` 后再擦除。擦除期间暂停采样，随后重新启动转换。

## 存储布局

固件针对 `0B 40 13` 的 512 KiB Flash 配置日志区 `0x011000`–`0x07FFFF`。每条记录占 10 字节，每个 4 KiB 扇区保存 409 条；111 个扇区共 **45,399 条**，每秒一条约可记录 **12 小时 36 分 39 秒**。写满后停止新增，不自动覆盖旧记录。

**图纸与实测芯片存在差异：**原理图中 U2 标注为 XT25F02（2 Mbit），此前实机读取的 JEDEC ID 为 `0B 40 13`，与 XT25F04 系列的 4 Mbit（512 KiB）规格对应。扩容布局依据该次实测 ID；用于其他开发板前，请核实 Flash 实际型号及容量，不能仅凭图纸假定可用至 `0x07FFFF`。

前 409 条与旧版本 DS18B20 日志地址兼容，`0x010000` 的旧 NTC 扇区不在日志擦除范围内。固件在写入新扇区前检查空白状态；若扇区包含未知数据，会报告日志故障而非自动擦除。

## 已验证与限制

- 实机串口记录曾从 `#409` 继续到 `#410` 及以后，`D` 导出以 `END` 结束；重启后记录数量恢复，断电重插也经用户检查。
- 程序设计容量是计算值，未进行写满 45,399 条的完整耐久测试。按键、指示灯以及电池独立供电应根据实物单独验收。
- DS18B20 标称范围为 −55～+125 ℃；其数据手册给出的全量程误差为 ±2 ℃，因此不能据此保证全量程 ±1.5 ℃。参见 [DS18B20 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/ds18b20.pdf)。
- 本项目保留 ARM 启动与系统文件中的原始版权及使用条款。开发板原理图的署名和来源保留在原 PDF 中；公开发布前请确认第三方文件的再分发许可。本项目尚未指定统一开源许可证。
